# 多语言网站

tifa 没有语言设置。语言是 URL 的一部分，由 Go 检查，页面从那里取用。规则写在[多语言网站](../app.zh-CN.md#多语言网站)和[内容](../content.zh-CN.md)里，[examples/shop](../../examples/shop/app/store) 的店面是一份大的可运行样例。这篇从第一个目录做到测试，做一个小网站，并把这些零件串起来：语言列表放哪、谁来选语言、界面和文章怎么翻译、搜索引擎怎么知道哪个页面是哪个。

这个网站叫 `lingo`，有首页、文章列表和文章页，语言是英文（`en`，默认）和中文（`zh-CN`）。一篇文章两种语言都有，一篇只有英文。代码是用 `tifa new` 生成的真实应用，用 `tifa check` 构建并检查过。

## 取舍

- **每种语言一个 URL，默认语言也一样。** `/en/posts` 和 `/zh-CN/posts`。打开同一个 URL 的人看到的页面都一样，所以它能放进[整页缓存](../app.zh-CN.md#整页缓存)，能被链接，能被搜索引擎收录。只靠 cookie 或 `Accept-Language`，就会让一个 URL 对应两个页面。
- **语言只来自 URL。** 访客的 cookie 和浏览器语言只在 `/` 用一次，用来挑一个 URL。没有页面读它们。
- **语言列表只有一份，在 Go 里。** 页面把列表当数据拿。语言代码写成搜索引擎读得懂的样子（`en`、`zh-CN`），到处都用同一个：URL 里、`content/` 下的目录名、界面文案的键。
- **只显示存在的。** 没有中文版的文章不在中文列表里，它的英文页也不声称有中文对应版本。在中文 URL 下用英文文字兜底，会让一个页面混着两种语言。

## 一份语言列表

根目录的 `languages.go` 是唯一列出语言和语言名的地方：

```go
// languages.go
package lingo

// Language is one language of the site.
type Language struct {
	Code string `json:"code"`
	// Name is the language written in itself, for the language switch.
	Name string `json:"name"`
}

// Languages are the languages of the site, the default one first.
var Languages = []Language{
	{Code: "en", Name: "English"},
	{Code: "zh-CN", Name: "简体中文"},
}

// FindLanguage returns the language of a code from the URL, or tifa.ErrNotFound.
func FindLanguage(code string) (Language, error) {
	for _, l := range Languages {
		if l.Code == code {
			return l, nil
		}
	}
	return Language{}, tifa.ErrNotFound
}
```

内容集合必须在 `content.go` 里用字面量写出它的语言（原因见[声明集合](../content.zh-CN.md#声明集合)），所以列表要写两遍。用一个测试让两处保持一致：

```go
func TestLanguagesMatchTheCollection(t *testing.T) {
	var codes []string
	for _, l := range Languages {
		codes = append(codes, l.Code)
	}
	if !slices.Equal(codes, Posts.Languages()) {
		t.Fatalf("Languages %v, Posts.Languages() %v", codes, Posts.Languages())
	}
}
```

## Layout 检查语言

`app/lang+` 的 Layout 是唯一的关口。站点没有的语言是 404，由上面的 Layout 显示（见[这个模式](../app.zh-CN.md#多语言网站)）。下面的页面用 `tifa.Use` 调用它，所以页面从不自己信任 `c.Param("lang")`：

```go
// app/lang+/route.go
package lang

// Shell is what every page shows around itself.
type Shell struct {
	Lang      string           `json:"lang"`
	Languages []lingo.Language `json:"languages"`
}

func Layout(c *tifa.Ctx) (Shell, error) {
	l, err := lingo.FindLanguage(c.Param("lang"))
	if err != nil {
		return Shell{}, err
	}
	return Shell{Lang: l.Code, Languages: lingo.Languages}, nil
}
```

```go
// app/lang+/posts/route.go
func Load(c *tifa.Ctx) (List, error) {
	s, err := tifa.Use(c, lang.Layout)
	if err != nil {
		return List{}, err
	}
	return List{Lang: s.Lang, Posts: Published(s.Lang), SEO: lingo.PageSEO(s.Lang, "/posts")}, nil
}
```

根 Layout 有一个 `Error`，在 `/fr` 和任何没有页面的 URL 上显示。那里不知道访客的语言，所以它写「Page not found · 页面不存在」，并给出两种语言的链接。

## 在 `/` 选语言

`/` 没有页面，只有一个方法处理函数。它把访客送到他之前选过的语言，没有的话送到最接近浏览器语言的那个（`golang.org/x/text/language` 的 [Matcher](https://pkg.go.dev/golang.org/x/text/language#Matcher) 知道 `en-GB` 离 `en` 比离 `zh-CN` 近）：

```go
// languages.go
var matcher = func() language.Matcher {
	var tags []language.Tag
	for _, l := range Languages {
		tags = append(tags, language.MustParse(l.Code))
	}
	return language.NewMatcher(tags)
}()

// Preferred returns the language closest to an Accept-Language header, the default one when
// none is close.
func Preferred(acceptLanguage string) Language {
	tags, _, _ := language.ParseAcceptLanguage(acceptLanguage)
	_, i, confidence := matcher.Match(tags...)
	if confidence == language.No {
		return Languages[0]
	}
	return Languages[i]
}
```

```go
// app/route.go
func GET(c *tifa.Ctx) error {
	c.Writer().Header().Add("Vary", "Cookie, Accept-Language")
	if picked, err := c.Cookie(lingo.LangCookie); err == nil {
		if l, err := lingo.FindLanguage(picked.Value); err == nil {
			return tifa.Redirect("/"+l.Code, http.StatusFound)
		}
	}
	return tifa.Redirect("/"+lingo.Preferred(c.Header("Accept-Language")).Code, http.StatusFound)
}
```

它是 302，因为答案取决于访客，并且用 `Vary` 说明取决于什么。cookie 里放的不是站点的语言时，会被忽略。

### 记住选择

没有 cookie 的话，访客切到中文，下次来到 `/`，又回到浏览器说的语言。如果你在意这个，就把选择记下来。如果你的读者大多用浏览器要求的语言，就跳过这一节：URL 本身已经是记忆。

语言切换里的链接走一个 Go 的小路由，它设置 cookie 然后跳到页面：

```go
// app/lang+/remember/route.go
package remember

func GET(c *tifa.Ctx) error {
	l, err := lingo.FindLanguage(c.Param("lang"))
	if err != nil {
		return err
	}
	c.SetCookie(&http.Cookie{
		Name: lingo.LangCookie, Value: l.Code, Path: "/", MaxAge: int(365 * 24 * time.Hour / time.Second),
		HttpOnly: true, SameSite: http.SameSiteLaxMode,
	})
	to := c.Query("to")
	// Only go on to a page of the language itself. Anything else, such as an address on another
	// site, is dropped, so this URL cannot be used to send visitors elsewhere.
	if to != "/"+l.Code && !strings.HasPrefix(to, "/"+l.Code+"/") || strings.ContainsAny(to, "\\\r\n") {
		to = "/" + l.Code
	}
	c.Writer().Header().Set("Cache-Control", "no-store")
	return tifa.Redirect(to, http.StatusFound)
}
```

- **它放在 `lang+` 下，不是单独一个目录。** `/pick/{lang}` 会让构建失败：`the path "/pick/{lang}" conflicts with "/{lang}/posts" of app/lang+/posts: both match some URLs and neither is more specific`。第一段是字面量、第二段是参数的路径，不能和第一段是参数、第二段是字面量的路径并存（见[目录就是 URL](../app.zh-CN.md#目录就是-url)）。
- **`to` 来自访客，** 所以只跟随所选语言下的路径。有测试会发 `https://evil.example`、`//evil.example`、另一种语言的路径和反斜杠。
- **切换链接是普通的 `<a>`，** 不是路由的 `Link`，因为目标是 Go 的路由，不是页面。
- **没有页面读这个 cookie。** 读了的页面没法缓存，一个 URL 还会显示两种语言。

## 翻译界面

界面文案是每种语言一个 JSON 文件，随应用打包，每种语言一个 i18next 实例：

```json
// app/lang+/locales/en.json
{
  "site": { "name": "Lingo" },
  "nav": { "home": "Home", "posts": "Posts", "language": "Language" },
  "home": { "title": "Home", "lead": "Notes from a small studio, in two languages." },
  "posts": {
    "title": "Posts",
    "count_one": "{{count}} post",
    "count_other": "{{count}} posts",
    "published": "Published {{date, datetime(dateStyle: medium; timeZone: UTC)}}",
    "back": "All posts"
  }
}
```

```ts
// app/lang+/i18n.ts
import i18next, { type i18n } from 'i18next'
import en from './locales/en.json'
import zhCN from './locales/zh-CN.json'

// Every message of every language is bundled with the app, so init runs at once and the server
// render has all of them.
const resources = {
  en: { translation: en },
  'zh-CN': { translation: zhCN },
}

const instances = new Map<string, i18n>()

// i18nFor returns the i18next instance of a language, made once per language. The language comes
// from the data of the language Layout, which Go has checked.
export function i18nFor(lang: string): i18n {
  let instance = instances.get(lang)
  if (!instance) {
    instance = i18next.createInstance()
    instance.init({
      lng: lang,
      fallbackLng: false,
      resources,
      initAsync: false,
      interpolation: { escapeValue: false },
    })
    instances.set(lang, instance)
  }
  return instance
}
```

Layout 把实例交给它下面的页面：

```tsx
// app/lang+/layout.tsx
export default function Language() {
  const { lang } = layout.useLoaderData()
  return (
    <I18nextProvider i18n={i18nFor(lang)}>
      <Header />
      <Outlet />
    </I18nextProvider>
  )
}
```

页面里调用 `const { t } = useTranslation()`，写 `t('posts.back')`。原因在[多语言网站](../app.zh-CN.md#多语言网站)里：所有文案一次加载好（`initAsync: false`），所以服务端 HTML 里有文字，浏览器 hydrate 时用的是同样的文字，语言取自 Layout 的数据。

- **实例按语言建，不按请求建，** 每种语言一个，所以没有请求能改变别的请求看到的东西。
- **`fallbackLng: false`。** 中文里缺的键会显示成键本身，评审时一眼就看到。悄悄回退到英文会把缺口藏起来。网站变大后，加一个测试检查两个文件的键相同。
- **复数跟着语言走。** 英文用 `count_one` 和 `count_other`，中文只有 `count_other`，因为它没有单数形式。服务端有 `Intl.PluralRules`。
- **日期在文案里带着时区**（`datetime(dateStyle: medium; timeZone: UTC)`），所以服务端和每个浏览器打印出一样的文字（见[怎么写才能水合一致](../app.zh-CN.md#怎么写才能水合一致)）。
- **页面标题写在组件之外，** 所以直接用实例：`i18nFor(loaderData.lang).t('posts.title')`。
- **服务端渲染的 i18next 缓存**默认是开的，这里没问题。什么时候要关，见 [`build.i18next_cache`](../config.zh-CN.md#配置项)。

## 两种语言的文章

`content.go` 声明语言，文件按语言分目录放（见[内容](../content.zh-CN.md)）：

```go
// content.go
var Posts = content.Define[Post](content.Source{Dir: "posts", Languages: []string{"en", "zh-CN"}})

type Post struct {
	content.Entry
	Title   string `json:"title"`
	Summary string `json:"summary"`
}
```

```markdown
<!-- content/posts/zh-CN/hello/index.md -->
---
title: 来自工作室的问候
summary: 我们为什么用两种语言写作。
date: 2026-10-01
slug: ni-hao
---
```

`content/posts/en/hello/index.md` 的 path 和它相同，所以 tifa 把这两个当作互为译文（见 [ID、slug、path 和语言](../content.zh-CN.md#idslugpath-和语言)）。中文 URL 用它自己的 slug，`/zh-CN/posts/ni-hao`，英文的是 `/en/posts/hello`。`Entry.Translations` 列出两者和它们的 slug。path 不同的译文，在 front matter 里用 `translationKey` 连起来。

领域代码每次只向集合要一种语言：

```go
// app/lang+/posts/post.go
func Published(lang string) []lingo.Post {
	list := lingo.Posts.In(lang) // drafts and posts still to come are left out
	slices.SortStableFunc(list, func(a, b lingo.Post) int { return b.Date.Compare(a.Date) })
	return list
}

func BySlug(lang, slug string) (lingo.Post, error) {
	for _, p := range lingo.Posts.In(lang) {
		if p.Slug == slug {
			return p, nil
		}
	}
	return lingo.Post{}, tifa.ErrNotFound
}
```

`/en/posts/ni-hao` 是 404：slug 属于它的语言。缺译文的内容，`tifa build` 会打印一行，所以每次构建你都能看到缺口：

```text
tifa: content: 1 entry of posts has no zh-CN version: only-english (warning)
```

## 语言之间的链接

搜索引擎读页面 head 里的两种链接（见 [Google 对多语言版本的规则](https://developers.google.com/search/docs/specialty/international/localized-versions)）：

- 页面每个版本的 `rel="alternate" hreflang`，包括页面自己，用完整地址（`https://...`），再加一个 `x-default`，给哪种语言都不合适的访客。每个版本都必须指回其他版本，否则这些链接会被忽略。
- `rel="canonical"`，页面自己的地址，不带查询串。

这些地址需要站点的公开地址，每次部署都不一样，所以它是一项设置：

```go
// config.go
var SiteURL = tifa.String("site.url", "http://127.0.0.1:9527", "Public address of the site, without a trailing slash")
```

在服务器上设 `SITE_URL=https://example.com`。链接在 Go 里生成，就在它们所依据的数据旁边，并作为页面 `Load` 结果的一部分送到页面：

```go
// languages.go
// An Alternate is the same page in another language, with its full address.
type Alternate struct {
	// Lang is a language code, or x-default for visitors none of the languages suits.
	Lang string `json:"lang"`
	Href string `json:"href"`
}

// SEO is what the head of a page needs to tell search engines which page this is and where its
// translations are.
type SEO struct {
	Canonical  string      `json:"canonical"`
	Alternates []Alternate `json:"alternates"`
}

func url(lang, path string) string {
	return strings.TrimSuffix(SiteURL, "/") + "/" + lang + path
}

// PageSEO is the SEO of a page that exists in every language at the same path below the
// language, such as "/posts". Use "" for the home page of a language.
func PageSEO(lang, path string) SEO {
	var alts []Alternate
	for _, l := range Languages {
		alts = append(alts, Alternate{Lang: l.Code, Href: url(l.Code, path)})
	}
	return SEO{Canonical: url(lang, path), Alternates: withDefault(alts)}
}

// PostSEO is the SEO of a post: it lists only the languages the post has.
func PostSEO(p Post) SEO {
	var alts []Alternate
	for _, t := range p.Translations {
		alts = append(alts, Alternate{Lang: t.Lang, Href: url(t.Lang, "/posts/"+t.Slug)})
	}
	return SEO{Canonical: url(p.Lang, "/posts/"+p.Slug), Alternates: withDefault(alts)}
}

// withDefault adds x-default, pointing at the version in the default language when there is one.
func withDefault(alts []Alternate) []Alternate {
	for _, a := range alts {
		if a.Lang == Languages[0].Code {
			return append(alts, Alternate{Lang: "x-default", Href: a.Href})
		}
	}
	return alts
}
```

页面的 head 把这些数据变成标签：

```ts
// app/lang+/seo.ts
type SEO = { canonical: string; alternates: Array<{ lang: string; href: string }> }

// seoHead gives a page its title and the links search engines read: the page's own address, and
// the same page in each language it has.
export function seoHead(title: string, seo: SEO) {
  return {
    meta: [{ title }],
    links: [
      { rel: 'canonical', href: seo.canonical },
      ...seo.alternates.map((a) => ({ rel: 'alternate', hrefLang: a.lang, href: a.href })),
    ],
  }
}
```

```tsx
// app/lang+/posts/post+/page.tsx
export const head = ({ loaderData }: { loaderData?: PageData }) => (loaderData ? seoHead(loaderData.post.title, loaderData.seo) : {})
```

Layout 只设置 `<html lang>`：

```tsx
// app/lang+/layout.tsx
export const head = ({ loaderData }: { loaderData?: LayoutData }) => ({
  htmlAttributes: { lang: loaderData?.lang },
})
```

为什么链接由各个页面给出，而不是像店面那样由 Layout 给出：店里每个页面都有两种语言，所以它的 Layout 可以在一处为所有页面写链接（见 [Layout 的 head](../app.zh-CN.md#多语言网站)）。这里一篇文章可能只有一种语言，只有页面自己知道。每个页面都有所有语言时用 Layout 的做法，译文不齐时用页面的做法。页面失败时两种做法都会省掉链接：没有数据的页面没有 `loaderData`，它的 head 是空的，回答 404 的 URL 不会被指向。

服务器为有译文的文章的英文页，和没有中文版的那篇发出的内容（`SITE_URL=https://example.com`）：

```html
<!-- /en/posts/hello -->
<html lang="en"> ... <title>Hello from the studio</title>
<link rel="canonical" href="https://example.com/en/posts/hello">
<link rel="alternate" hrefLang="en" href="https://example.com/en/posts/hello">
<link rel="alternate" hrefLang="zh-CN" href="https://example.com/zh-CN/posts/ni-hao">
<link rel="alternate" hrefLang="x-default" href="https://example.com/en/posts/hello">

<!-- /en/posts/only-english -->
<link rel="canonical" href="https://example.com/en/posts/only-english">
<link rel="alternate" hrefLang="en" href="https://example.com/en/posts/only-english">
<link rel="alternate" hrefLang="x-default" href="https://example.com/en/posts/only-english">
```

第一篇文章的中文页列出同样的三个 alternate，所以链接来回互指。

## 语言切换

切换按语言各自的名字显示其他语言，并跳到那个语言下的同一个页面。对文章来说，同一个页面就是它的译文，slug 不同。页面本身已经知道：切换读取页面 `Load` 给搜索引擎的那些链接，页面在那个语言里没有版本时，退到该语言的首页。

```tsx
// app/lang+/layout.tsx
function useWhere() {
  const matches = useMatches()
  const seo = (matches[matches.length - 1]?.loaderData as { seo?: { alternates: Array<{ lang: string; href: string }> } } | undefined)?.seo
  return (code: string) => {
    const href = seo?.alternates.find((a) => a.lang === code)?.href
    return href ? new URL(href).pathname : `/${code}`
  }
}

// in Header, for each language that is not the current one:
<a href={`/${l.code}/remember?to=${encodeURIComponent(where(l.code))}`} hrefLang={l.code} lang={l.code} rel="nofollow">
  {l.name}
</a>
```

链接上的 `lang` 告诉读屏软件这个名字是用它自己的语言写的，`rel="nofollow"` 让爬虫别去爬 cookie 路由（它们通过 head 里的 alternate 链接找到各种语言）。对没有中文版的文章，中文链接指向 `/zh-CN`。

## 测试

```go
func TestPreferred(t *testing.T) {
	for header, want := range map[string]string{
		"":                        "en",
		"zh-TW,zh;q=0.9,en;q=0.5": "zh-CN",
		"en-GB":                   "en",
		"fr-FR":                   "en", // none is close: the default
		"zh-CN":                   "zh-CN",
	} {
		if got := Preferred(header).Code; got != want {
			t.Errorf("Preferred(%q) = %s, want %s", header, got, want)
		}
	}
}

// A post lists only the languages it has, under the slug it has in each.
func TestPostSEOFollowsTheTranslations(t *testing.T) {
	old := SiteURL
	SiteURL = "https://example.com"
	t.Cleanup(func() { SiteURL = old })
	hello := func(lang, slug string) Post {
		return Post{Entry: content.Entry{ID: "hello", Lang: lang, Slug: slug, Path: "hello"}}
	}
	tifatest.SetContent(t, Posts, hello("en", "hello"), hello("zh-CN", "ni-hao"), Post{Entry: content.Entry{ID: "alone", Lang: "en", Slug: "alone", Path: "alone"}})
	en, err := Posts.Get("en", "hello")
	if err != nil {
		t.Fatal(err)
	}
	got := PostSEO(en)
	want := []Alternate{
		{"en", "https://example.com/en/posts/hello"},
		{"zh-CN", "https://example.com/zh-CN/posts/ni-hao"},
		{"x-default", "https://example.com/en/posts/hello"},
	}
```
